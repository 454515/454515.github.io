## 一、产品概述

### 1.1 产品定位
一款运行于Windows平台的本地桌面OCR识别工具，主打身份证信息快速提取，支持多种图片导入方式，识别结果可一键复制粘贴到Excel，全程本地运算、数据不上传，保障隐私安全。

### 1.2 产品目标
- 解决身份证信息手动录入Excel效率低、易出错的痛点
- 提供微信拖拽、文件选择、剪贴板粘贴、文件夹导入等多种便捷输入方式
- 识别结果结构化展示，支持一键复制直接适配Excel分列
- 全程本地处理，确保身份证等敏感数据隐私安全
- 预留扩展能力，后续可无缝接入发票识别等更多卡证类型

### 1.3 目标用户
个人自用用户，需要频繁将身份证信息录入Excel表格，对数据隐私有一定要求。

### 1.4 使用场景
- **场景一**：手机拍摄身份证照片，通过微信传到电脑，拖拽到软件中识别，复制结果粘贴到Excel
- **场景二**：批量处理一个文件夹内的多张身份证图片，一次性识别全部后汇总复制
- **场景三**：截图身份证图片后，直接Ctrl+V粘贴到软件中识别
- **场景四**：识别结果有微小误差时，直接在软件内修改后再复制

## 二、功能需求

### 2.1 核心功能模块

#### 2.1.1 身份证识别
| 功能点 | 需求描述 | 优先级 |
|--------|----------|--------|
| 字段提取 | 准确识别身份证正面的**姓名、性别、公民身份号码**三个核心字段 | P0 |
| 识别准确率 | 清晰正常的身份证图片，字段识别准确率≥98% | P0 |
| 格式校验 | 身份证号自动校验18位格式，末位X自动统一为大写 | P1 |
| 自动方向校正 | 自动识别图片旋转角度，支持倒拍、横拍等各种角度的身份证 | P0 |
| 透视矫正 | 自动检测身份证边框，对倾斜、仰拍的图片进行透视矫正后再识别 | P1 |
| 背景去除 | 自动抠出身份证区域，去除桌面、手指等背景干扰 | P1 |

#### 2.1.2 图片导入（四种方式全支持）
| 功能点 | 需求描述 | 优先级 |
|--------|----------|--------|
| 微信拖拽 | 支持从微信聊天窗口直接拖拽图片到软件窗口，拖入即识别 | P0 |
| 文件选择 | 提供"选择文件"按钮，打开文件对话框选择单张或多张图片 | P0 |
| 剪贴板粘贴 | 软件窗口激活状态下，支持Ctrl+V粘贴剪贴板中的图片 | P0 |
| 文件夹导入 | 支持拖拽整个文件夹到软件，自动识别文件夹内所有图片（jpg/png格式） | P0 |
| 拖拽反馈 | 图片拖入窗口时，边框高亮变色，提示"释放即可识别" | P1 |

#### 2.1.3 批量识别
| 功能点 | 需求描述 | 优先级 |
|--------|----------|--------|
| 批量处理 | 支持一次导入多张图片，按导入顺序自动依次识别 | P0 |
| 进度显示 | 批量识别时显示进度条和状态文字，如"正在识别第 3 张 / 共 10 张" | P0 |
| 结果汇总 | 所有识别结果按顺序展示在结果列表中 | P0 |
| 失败处理 | 单张识别失败时，跳过并继续识别下一张，最后汇总失败数量 | P1 |

#### 2.1.4 结果展示与操作
| 功能点 | 需求描述 | 优先级 |
|--------|----------|--------|
| 表格展示 | 识别结果以表格形式展示，列序为：序号、姓名、性别、身份证号 | P0 |
| 一键复制 | 提供"复制全部"按钮，复制内容为制表符分隔格式，粘贴到Excel自动分成三列 | P0 |
| 选中复制 | 支持勾选/选中多条结果，复制选中的内容 | P1 |
| 手动编辑 | 结果表格中的每个字段都支持直接点击编辑，修正识别错误 | P0 |
| 删除单条 | 支持删除单条识别结果 | P1 |
| 清空全部 | 支持一键清空所有识别结果 | P1 |

## 三、非功能需求

### 3.1 性能要求
| 指标 | 要求 |
|------|------|
| 单张识别速度 | 普通办公电脑CPU环境下，单张身份证识别耗时 ≤ 1.5秒 |
| 启动速度 | 软件冷启动时间 ≤ 3秒 |
| 批量处理 | 100张身份证批量识别无崩溃、无内存泄漏 |
| 内存占用 | 正常运行时内存占用 ≤ 500MB |

### 3.2 兼容性要求
| 项目 | 要求 |
|------|------|
| 操作系统 | 支持Windows 10、Windows 11（64位） |
| 图片格式 | 支持JPG、PNG、BMP等常见图片格式 |
| 运行环境 | 无需安装Python或其他运行库，单exe直接运行 |

### 3.3 隐私安全要求
| 项目 | 要求 |
|------|------|
| 数据本地处理 | 所有图片识别全程在本地完成，不上传任何数据到云端 |
| 无网络请求 | 软件运行过程中不发起任何网络请求 |
| 无数据残留 | 关闭软件后，识别结果不写入本地存储（当前版本无历史记录） |
| 临时文件清理 | 识别过程中产生的临时文件，软件关闭时自动清理 |

### 3.4 易用性要求
| 项目 | 要求 |
|------|------|
| 零学习成本 | 界面简洁直观，打开就能用，无需阅读说明书 |
| 操作路径短 | 核心功能（拖拽→识别→复制）不超过3步操作 |
| 反馈及时 | 每个操作都有明确的视觉反馈（拖拽高亮、进度显示、复制成功提示） |
| 容错性 | 导入非图片文件、损坏图片时，给出友好提示，不崩溃 |

## 四、技术选型建议

### 4.1 推荐技术栈
| 层级 | 技术选型 | 说明 |
|------|----------|------|
| 界面框架 | PySide6（Python） | 跨平台Qt界面框架，Python开发效率高，打包方便 |
| OCR引擎 | PaddleOCR（PP-OCRv4） | 百度开源中文OCR引擎，准确率高，完全免费，本地部署 |
| 图像处理 | OpenCV | 图片预处理、透视矫正、边缘检测 |
| 打包工具 | PyInstaller | 打包成单exe文件，免安装 |

### 4.2 架构设计
采用模块化分层架构，便于后续扩展：

```
┌─────────────────────────────────┐
│         界面层（UI）            │  PySide6 界面、拖拽、表格、交互
├─────────────────────────────────┤
│         业务逻辑层              │  识别调度、批量处理、结果管理
├─────────────────────────────────┤
│         OCR引擎层               │  PaddleOCR 通用识别接口
├─────────────────────────────────┤
│         字段提取层              │  身份证处理器、发票处理器（预留）
├─────────────────────────────────┤
│         工具层                  │  图片预处理、剪贴板、格式转换
└─────────────────────────────────┘
```

**核心设计原则**：
- OCR引擎与业务逻辑解耦，后续更换引擎不影响上层
- 字段提取模块化，新增卡证类型只需新增对应处理器
- 界面与数据分离，便于后续迭代

### 4.3 识别流程
```
图片导入 → 图片预处理（灰度/矫正/增强） → PaddleOCR识别 → 身份证字段提取 → 结果展示
```

## 七、风险与注意事项

### 7.1 已知风险
| 风险 | 影响 | 应对方案 |
|------|------|----------|
| 模糊/反光图片识别准确率下降 | 识别错误率升高 | 增加图片预处理流程，提供手动编辑修正功能 |
| 单exe文件体积较大 | 启动稍慢、传输不便 | 选用轻量版OCR模型，优化打包配置 |
| 部分杀毒软件误报 | 用户不敢运行 | 提供代码签名（可选），说明是本地运行无风险 |

### 7.2 注意事项
- 本软件仅供个人自用，请勿用于非法用途
- 身份证信息属于敏感个人信息，请妥善保管识别结果
- 识别结果建议人工复核后再用于正式场合
