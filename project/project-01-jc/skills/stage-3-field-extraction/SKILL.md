# 阶段 3：身份证字段提取

## 目标
在 `src/processors/` 下实现 `IDCardProcessor`：接收阶段 1 的 OCR 文字块列表，提取**姓名、性别、公民身份号码**三个字段，并做格式校验（18 位、末位 X 统一大写）。预留 `BaseProcessor` 抽象，后续发票处理器按相同模式扩展。

## 前置条件
- 阶段 1、2 已完成验收。
- 已阅读 [spec-03-身份证字段提取.md](../../../docs/specs/spec-03-身份证字段提取.md)。

## 执行步骤

1. **读 spec**：明确字段提取规则、正则、格式校验逻辑、输出数据模型。
2. **实现基类**：`BaseProcessor`（抽象接口：`process(ocr_result) -> CardResult`）。
3. **实现 IDCardProcessor**：
   - 姓名提取：依据文字块位置（位于「姓名」标签右侧/后方）+ 中文模式。
   - 性别提取：识别「男 / 女」关键词。
   - 身份证号提取：正则匹配 17 位数字 + 末位数字或 X（x）。
4. **格式校验**：身份证号 18 位校验、末位 x → X 统一大写。
5. **自测**：用真实身份证 OCR 结果样例验证三字段提取正确率。
6. **验收**：对照 spec「验收标准」逐条核对。

## 完成标准
- [ ] 清晰正常图片上三字段提取准确率 ≥ 98%（用样例集实测统计）。
- [ ] 身份证号末位 x 自动转为大写 X。
- [ ] 结果字段缺失时返回空串 + 缺失标记，不崩溃。
- [ ] 已向用户汇报：提取规则、样例实测准确率。

## 注意事项
- 本层是纯函数式处理，**不接触 UI、不接触图片文件**，只吃文字块。
- 提取规则要兼顾「横向排版」与「竖向排版」两种身份证布局。
