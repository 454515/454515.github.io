# 阶段 6：批量识别与结果管理

## 目标
打通「导入 → 预处理 → OCR → 字段提取 → 结果展示」完整链路（PRD §4.3 识别流程），实现批量识别调度、进度条显示、结果表格编辑/删除/清空、以及复制到 Excel 的制表符格式输出。这是 V1.0 功能闭环的关键阶段。

## 前置条件
- 阶段 1/2/3 的接口已就绪，阶段 4/5 的 UI 与导入已就绪。
- 已阅读 [spec-06-批量识别与结果管理.md](../../../docs/specs/spec-06-批量识别与结果管理.md)。

## 执行步骤

1. **读 spec**：明确识别调度线程模型、进度回调、复制格式、编辑规则。
2. **实现识别服务**：`src/core/recognition_service.py`，用 `QThread`/线程池执行队列识别，避免阻塞 UI；单张失败跳过并计数。
3. **接通流水线**：每张图依次执行 预处理 → OCR 引擎 → IDCardProcessor 提取 → 结果入表。
4. **实现进度显示**：批量时显示进度条 + 「正在识别第 3 张 / 共 10 张」；单张识别隐藏进度条（PRD §2.2.2）。
5. **实现结果操作**：表格双击编辑（PRD §2.1.4 手动编辑）、删除单条、清空全部。
6. **实现一键复制**：「复制全部」输出制表符分隔文本（序号 姓名 性别 身份证号），粘贴 Excel 自动分三列；「选中复制」复制勾选行。
7. **自测**：批量 10 张实测，核对进度条、失败跳过、复制粘贴 Excel 分列效果。
8. **验收**：对照 spec「验收标准」逐条核对。

## 完成标准
- [ ] 完整识别链路跑通，真实图片 → 表格结果。
- [ ] 批量识别进度条 + 状态文字正常。
- [ ] 单张失败跳过继续，最后汇总失败数量。
- [ ] 复制全部粘贴到 Excel 自动分列。
- [ ] 双击可编辑、可删除单条、可清空全部。
- [ ] 已向用户汇报：端到端自测结果（含失败场景）。

## 注意事项
- 识别必须在后台线程，任何阻塞 UI 的实现都是缺陷。
- 复制内容只含制表符与换行，**不含多余空格/序号列约定**，以 spec 为准。
