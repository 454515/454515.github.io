# 阶段 2：图像预处理与矫正

## 目标
在 `src/utils/` 下实现图片预处理管线，为 OCR 提供「最利于识别」的图片。核心三项：**方向校正**（识别旋转角度）、**透视矫正**（检测身份证边框、拉正倾斜/仰拍图）、**背景去除**（抠出身份证区域）。

## 前置条件
- 阶段 1 已完成验收（OCR 引擎接口可用）。
- 已阅读 [spec-02-图像预处理与矫正.md](../../../docs/specs/spec-02-图像预处理与矫正.md)。

## 执行步骤

1. **读 spec**：明确预处理管线的调用顺序、各步骤输入输出、启用开关。
2. **实现方向校正**：基于文本方向检测 / 轮廓角度分析，返回 `0/90/180/270` 旋转角。
3. **实现透视矫正**：边缘检测 → 找身份证四边形的四个角点 → 透视变换拉正。
4. **实现背景去除**：基于四边形结果裁剪身份证区域。
5. **实现管线入口**：`preprocess_image()` 统一调度：方向校正 → 透视矫正 → 裁剪，返回处理后的图片与元信息。
6. **自测**：准备倾斜/倒拍/仰拍样例图，逐项验证输出方向正确、身份证区域完整。
7. **验收**：对照 spec「验收标准」逐条核对。

## 完成标准
- [ ] 预处理管线输入任意角度身份证图，输出正面朝上的图。
- [ ] 透视矫正后身份证边缘基本水平、文字可正常识别。
- [ ] 处理失败（如图中无身份证）返回明确标记，不抛出裸异常。
- [ ] 预处理全流程单张耗时控制在可接受范围（实测记录）。
- [ ] 已向用户汇报：各步骤实现方式与样例效果。

## 注意事项
- 本阶段不调用 OCR，只做图像处理；与阶段 1 的接口在本阶段结束时联调一次。
- 方向校正优先保证「识别成功」而非「方向绝对正确」。
