# 阶段 7：打包与交付

## 目标
将 V1.0 打包为单个免安装 exe（≤ 300MB、含图标），并通过 PRD §5.2 的 7 项全局验收与非功能需求（§3）。这是交付前的最后一关。

## 前置条件
- 阶段 6 已完成验收，功能闭环。
- 已阅读 [spec-07-打包与交付.md](../../../docs/specs/spec-07-打包与交付.md) 与 PRD §3、§5。

## 执行步骤

1. **读 spec**：明确打包命令、排除项、图标资源路径、验收清单。
2. **准备图标**：提供 `.ico` 图标文件放入 `assets/`，确认可显示。
3. **配置 PyInstaller**：按 spec 编写打包命令/`.spec` 文件，含 OCR 模型与依赖数据文件收集。
4. **打包**：执行 PyInstaller，产出单 exe，检查体积是否 ≤ 300MB。
5. **验证隐私红线**：检查程序不发起网络请求、不残留数据（对照 PRD §3.3）。
6. **全局验收**：逐条执行 PRD §5.2 的 7 项验收，记录结果；不合格则回到对应阶段修复。
7. **交付汇报**：向用户汇报 exe 路径、体积、验收结果表。

## 完成标准
- [ ] 单 exe 生成，双击可直接运行，免安装。
- [ ] exe 体积 ≤ 300MB，图标正常显示。
- [ ] 7 项全局验收全部通过。
- [ ] 断网状态下功能正常（本地处理验证）。
- [ ] 已向用户汇报完整验收结果与交付物位置。

## 注意事项
- PaddleOCR 模型需打包进 exe 或外置到同目录 `models/`，二者择一并在 spec 中定死，避免运行时找不到模型。
- 杀毒软件误报属已知风险（PRD §7.1），如实向用户说明，不做规避。
- 打包后务必在**未安装 Python 的干净环境**复测一次，确保无隐藏依赖。
