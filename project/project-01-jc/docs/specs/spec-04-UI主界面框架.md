# spec-04：UI 主界面框架

| 项 | 内容 |
|----|------|
| 所属阶段 | 阶段 4 |
| 对应 Skill | `stage-4-ui-main-window` |
| 依赖 | 阶段 3（数据模型可引用） |
| 对应 PRD | §2.2 界面布局、§2.2.2 交互细节 |

## 1. 阶段目标

用 PySide6 搭建主窗口的完整静态布局，与 PRD §2.2 的 ASCII 结构一致。本阶段只搭「壳」，识别通过模拟数据接入验证。

## 2. 范围

**包含**：
- 主窗口 `MainWindow`
- 顶部标签页（身份证可用 / 发票预留置灰）
- 中央拖拽区（静态占位）
- 操作按钮「选择文件」「粘贴图片」
- 进度条（默认隐藏）
- 结果表格（序号/姓名/性别/身份证号）
- 底部操作栏（共 N 条 / 复制全部 / 清空）
- 模拟数据填充方法

**不包含**：真实识别、导入、拖拽逻辑（阶段 5/6 职责）。

## 3. 模块结构 `src/ui/`

```
src/ui/
├── __init__.py
├── main_window.py     # 主窗口组装各组件
├── drop_area.py       # 中央拖拽区域（占位组件）
├── result_table.py    # 结果表格组件
└── bottom_bar.py      # 底部操作栏组件
```

## 4. 布局规格（对照 PRD §2.2）

从上到下：
1. **顶部标签页** `QTabWidget`：页 1「身份证识别」可选；页 2「发票识别(预留)」用 `setTabEnabled(1, False)` 置灰禁用。
2. **中央拖拽区域** `DropArea`：默认居中提示文字「拖拽图片到此处开始识别」「（支持微信拖拽/文件/文件夹/粘贴）」；占位组件，阶段 4 不做拖拽交互。
3. **操作按钮行**：「选择文件」「粘贴图片」两个 `QPushButton`。
4. **进度条** `QProgressBar`：默认 `hide()`。
5. **结果表格** `ResultTable`：
   - `QTableWidget`，4 列，列头 = 序号、姓名、性别、身份证号。
   - 双击可编辑（`editTriggers` 配置，编辑逻辑阶段 6 完善，本阶段先放开）。
   - 支持全选/复制（`QTableWidget` 默认能力）。
6. **底部操作栏** `BottomBar`：左侧「共 N 条结果」label，右侧「复制全部」「清空」按钮（本阶段仅显示，点击逻辑阶段 6 接）。

## 5. 数据接口

`MainWindow.add_demo_rows(rows: list[CardResult])`：临时方法，向表格填充模拟数据验证布局，阶段 6 用真实数据替换。

## 6. 自测规格

- `python src/app.py` 启动，核对：
  - 布局与 PRD §2.2 ASCII 结构一致。
  - 「发票识别」标签置灰不可点击。
  - 调用 `add_demo_rows` 填充 2 行数据后表格显示正常。
  - 窗口拉伸缩放，布局不塌陷错乱。
