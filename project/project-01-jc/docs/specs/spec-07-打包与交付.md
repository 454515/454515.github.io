## 1. 阶段目标

打包为单个免安装 exe（≤ 300MB、含图标），通过 PRD §5.2 的 7 项全局验收与非功能需求，完成 V1.0 交付。

## 2. 范围

**包含**：
- PyInstaller 打包配置
- 图标资源
- 模型文件打包策略
- 全局验收执行
- 隐私红线验证

**不包含**：新功能开发。

## 3. 打包配置

### 3.1 打包命令（在 `.venv` 内执行）

```
pyinstaller --noconfirm --onefile --windowed ^
  --name "检测识别" ^
  --icon "assets/icon.ico" ^
  --collect-all paddleocr ^
  --collect-all paddle ^
  --add-data "models;models" ^
  src/app.py
```

> 采用 **外置 `models/` 目录**（与 exe 同目录）策略，避免模型体积撑爆 exe，也便于更换模型。exe 启动时若同目录无 `models/` 则回退到默认下载路径，并提示。

### 3.2 图标
- `assets/icon.ico`，多尺寸（16/32/48/256）确保资源管理器显示正常。

### 3.3 体积控制
- 目标 ≤ 300MB。若超限：检查 `--exclude-module` 排除未用模块（如 matplotlib、scipy 若未使用），或改用 slim 模型。
