## 1. 阶段目标

打通「导入 → 预处理 → OCR → 字段提取 → 结果展示」完整链路，实现批量识别调度、进度显示、结果编辑/删除/清空、一键复制到 Excel。V1.0 功能闭环。

## 2. 范围

**包含**：
- 识别服务（后台线程调度）
- 完整识别流水线
- 批量进度显示
- 结果表格编辑 / 删除单条 / 清空全部
- 一键复制全部 / 选中复制（制表符分隔）

**不包含**：发票识别、历史记录、Excel 导出（PRD §2.3 预留，V1.0 不实现）。

## 3. 识别服务 `src/core/recognition_service.py`

```python
class RecognitionService(QObject):
    # 信号（Qt 信号，用于 UI 线程安全更新）
    progress_updated = Signal(int, int)      # (current, total)
    image_started = Signal(str)              # 当前识别的文件名
    result_ready = Signal(CardResult, str)   # (识别结果, 源路径)；失败时 result.fields 全空
    batch_finished = Signal(int)             # 失败数量
    def __init__(self, engine: OcrEngine, preprocess: callable, processor: IDCardProcessor): ...
    def start_batch(self, images: list[ImportedImage]) -> None: ...  # 后台线程开始
    def stop(self) -> None: ...              # 中止当前批次
```

**规格**：
- **线程模型**：用 `QThread` + 信号槽；识别循环在后台线程执行，绝不在 UI 线程阻塞。
- **逐张流水线**：`preprocess_image(path)` → `engine.recognize(processed)` → `processor.process(ocr_result)`。
- **失败跳过**：单张任一环节异常 → 跳过，计数，继续下一张；`result_ready` 发出 `fields` 全空的结果供表格标记。
- **中止**：`stop()` 后当前张完成后不再取新张。

## 4. 批量识别与进度（PRD §2.1.3）

- 批量识别（队列 > 1 张）时显示进度条 + 状态文字「正在识别第 N 张 / 共 M 张」。
- 单张识别（队列 == 1）时**隐藏进度条**（PRD §2.2.2）。
- 全部完成时在状态区显示「完成，失败 N 张」。
- `progress_updated` 驱动 `QProgressBar.setValue` 与状态 label。

## 5. 结果管理（PRD §2.1.4）

### 5.1 表格展示
- 列序：序号、姓名、性别、身份证号。
- 每张识别结果按顺序追加行；失败行三字段显示「识别失败」。

### 5.2 手动编辑（P0）
- 双击单元格进入编辑，保存后更新对应数据。

### 5.3 删除单条（P1）
- 选中行右键或删除按钮 → 移除该行，重新编号。

### 5.4 清空全部（P1）
- 「清空」按钮 → 确认后清空表格与数据，总数归零。

### 5.5 一键复制（P0）
- 「复制全部」：将全部行序列化为**制表符分隔**文本写入剪贴板：

```
序号\t姓名\t性别\t身份证号
1\t张三\t男\t110101199001011234
2\t李四\t女\t310101199202025678
```

- 粘贴到 Excel 自动分三列（忽略序号列即为三列数据，以 spec 为准）。
- 复制成功用状态提示「已复制 N 条」。

### 5.6 选中复制（P1）
- 勾选/选中多条行 → 仅复制选中行，格式同上。

## 6. 自测规格

1. 批量 10 张样例图：进度条递增、状态文字正确、10 条结果入表。
2. 混入 1 张损坏图片：跳过继续，完成时失败数量 = 1。
3. 复制全部 → 粘贴到 Excel 验证自动分列。
4. 双击单元格改错字 → 表格更新。
5. 删除单条 → 行移除、序号重排；清空 → 表格空、总数 0。
6. 识别期间操作 UI 不卡顿。
